# Client portfolio

Отдельный сайт Александра Халтурина для частных клиентов и небольших команд. Он не дублирует резюме: услуги сформулированы через бизнес-задачи, кейсы показывают готовые сценарии, а интерактивный бриф собирает первое сообщение для Telegram.

## Локальный запуск

```powershell
python -m http.server 4181 --directory .
```

Открыть: `http://127.0.0.1:4181/`

## Проверка

```powershell
node scripts/check-site.cjs
node --check app.js
```

Сайт не зависит от соседнего резюме-портфолио и может публиковаться как самостоятельный проект.
